# AgentForge 1.0.7 for macOS (Apple Silicon)

Download the DMG and drag AgentForge to Applications. This release is built from the AgentForge 1.0.7 Studio with the macOS desktop integrations.

- Configure Deploy, Ollama Cloud, OpenAI, Claude, DeepSeek, Gemini, and custom provider keys in Settings. Enter your own provider key.
- The interview suggests a product type from your first request.
- HTML wireframes and prototypes appear as their pages are generated and checked. Use the selection tools to move or resize elements and add picture placeholders to wireframes.
- The builder uses prompts for the selected stack and checks user journeys.

The app bundles Python 3.12, Node.js 24, and Playwright Chromium. The app has an ad-hoc signature. Apple notarization is required for standard Gatekeeper approval.
