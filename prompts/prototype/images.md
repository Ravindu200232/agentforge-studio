# Sample photographs for the prototype

Some pages of a prototype are, in part, photographic: people, places, products,
scenes. Real sample photographs make them convincing; nothing else does. Decide which
photographs, if any, this product's pages call for.

Return one to six subjects, each a short plain phrase a person would type into a photo
search (a place, a thing, a moment — never a brand or a person's name), and where it is
used. If the product's screens do not call for photography at all (a tool, a dashboard,
an admin console, a form), return an empty list: drawing with SVG is better than a
photograph that does not belong.

Return JSON only, nothing before or after it:

```json
{"subjects": [{"subject": "…", "used_on": "…"}]}
```
