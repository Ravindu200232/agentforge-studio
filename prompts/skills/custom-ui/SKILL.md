# Project UI

Write the UI for this product with semantic HTML and the app's existing frontend stack. The wireframe and prototype use React, TypeScript and Tailwind CSS. Use Lucide icons where available and helpful. Write the shared shell, fields, tables, actions, and feedback states the product needs as local components and reuse them across pages.

Do not install, generate from, or copy ready-made UI components, registries, templates, or blocks. This includes shadcn/ui, Radix UI, and other component libraries. On a resumed project keep working screens intact and use project-authored components for new UI.

Use native controls with accessible labels, keyboard operation and visible focus. Use native dialog behavior for modal interactions. Follow the supplied product routes, approved layout and styling guidance, and keep the Studio's router and demo session helpers intact. The Studio handles bundling.
