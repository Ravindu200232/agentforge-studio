# Look things up before drawing

You are about to draw the screens of a product as low-fidelity wireframes. Before
drawing anything, look up how good products of this kind lay out their screens.

Write one to three web search queries. Each one names a kind of product or a kind
of screen that this product really has (a list, a form, a board, a dashboard, a
detail page, a settings screen, a sign-in page …) and asks for layout, wireframe
or UX patterns for it. Different queries should look at different kinds of
screen, so that between them they cover the product's main shapes.

Write them the way a person types into a search box: plain words, no quotation
marks, no site names, and no terms that only this product uses.

Return JSON only, nothing before or after it:

```json
{"queries": ["…", "…"]}
```
